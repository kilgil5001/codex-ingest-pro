## ⚡ 메인 실행 플로우 - MVP 배포 기준 상세 트리

아래 트리는 주소 입력부터 최종 패키지 전달까지의 전체 파이프라인을 코드 수준에서 구현할 때 필요한 단계와 모듈 책임을 정리한 것입니다. 각 단계는 Temporal 워크플로우의 Activity로 대응되며, 실패 시 재시도/보정 로직을 명시합니다.

### 🔍 1단계: 주소 분석 및 기초 데이터 수집 (Site Analyzer)
1.1 주소 입력 처리
├─ 1.1.1 `NormalizeAddressTask`
│   ├─ 도로명 ↔ 지번 변환 (행안부 API)
│   ├─ 맞춤법/특수문자 정규화
│   └─ 실패 시 사용자 확인 요청 (Webhook)
├─ 1.1.2 `GeocodeTask`
│   ├─ 카카오맵/네이버 API 우선 호출 → 좌표 획득
│   ├─ 좌표 신뢰도 < 0.8일 경우 후보 리스트 반환 → 사용자 선택 대기
│   └─ 좌표계 변환 (UTM-K) + 고도 정보 (국토지리정보원 DEM)
└─ 1.1.3 `FetchAdministrativeArea`
    ├─ 시/군/구 코드 매핑 (행정구역 테이블)
    ├─ 건축허가 관할청 식별
    └─ 인허가 담당자 메타데이터 캐시 조회

1.2 지적·도시계획 정보 취합
├─ 1.2.1 `FetchCadastralInfo`
│   ├─ VWorld API 호출 → 필지 경계 GeoJSON 저장
│   ├─ 소유 구분 (사유/국공유) 및 면적 검증
│   └─ 인접 도로 데이터 결합
├─ 1.2.2 `AnalyzeTopography`
│   ├─ DEM → 평균 경사도, 표고 계산
│   └─ 배수/배면 조건 추정 (지형 기반)
└─ 1.2.3 `CollectZoningRules`
    ├─ 도시계획 데이터베이스에서 용도지역/지구/구역 조회
    ├─ 지구단위계획 여부 확인 (문서 OCR → 규칙 파싱)
    └─ 용적률/건폐율/높이/이격 한도 산출

### 📋 2단계: 법규 분석 및 제약조건 산출 (Compliance Engine)
2.1 건축법 규칙 평가
├─ 2.1.1 `CalculateCoverageRatio`
│   ├─ 기본값: 용도지역 표준
│   ├─ 가중치: 지구단위 계획, 특별법, 도로 폭 기반 보정
│   └─ 결과: `coverage_limit` 저장
├─ 2.1.2 `CalculateFAR`
│   ├─ 인센티브 요건 (공공기여, 친환경) 평가
│   └─ 최대 허용 용적률 산출 + 근거 레퍼런스 링크 저장
├─ 2.1.3 `EvaluateHeightRestrictions`
│   ├─ 일조권 사선, 상대높이, 경관지구 체크
│   └─ 시뮬레이션 입력값(도로 폭, 인접 건물 높이) 저장
└─ 2.1.4 `ComputeSetbacks`
    ├─ 전/측/후면 이격 거리 계산
    ├─ 대지 안의 공지 요구 조건 산출
    └─ 결과를 GeoJSON Constraint Layer로 저장

2.2 소방법/주차장법/기타 규정
├─ 2.2.1 `FireCodeEvaluator`
│   ├─ 피난계단/부속실 조건 생성
│   ├─ 스프링클러/소화전 필요 여부
│   └─ 소방차 진입 경로 체크 (도로 폭 + 회전 반경)
├─ 2.2.2 `ParkingRequirementCalculator`
│   ├─ 용도별 주차 대수 계산 (세대수, 면적 기반)
│   └─ 장애인/경차 비율, 주차 구획 규격 정의
└─ 2.2.3 `SpecialLawChecker`
    ├─ 장애인·노인·임산부 편의증진법 적용 항목
    ├─ 녹색건축물/에너지 절약 설계 기준 필수 값
    └─ 지역 특화 조례 매핑 (그래프 DB 질의)

### 💰 3단계: 시장 조사 & 사업성 분석 (Market Intelligence + Proforma)
3.1 시장 데이터 수집
├─ 3.1.1 `CollectSalesInfo`
│   ├─ 반경 1km 분양 현황, 평형/분양가
│   ├─ 경쟁 프로젝트 스코어링 (성공 지표)
│   └─ 미분양 위험 요인 정리
├─ 3.1.2 `FetchTransactionRecords`
│   ├─ 최근 3년 실거래가 API → 시계열 정제
│   ├─ 상승률/계절성 분석 → Prophet 예측 모델 입력
│   └─ 거래량 기반 시장 온도 지수 산출
└─ 3.1.3 `AnalyzeLeaseMarket`
    ├─ 임대료 수준, 공실률, 수익률 계산
    └─ 임대 전략 (장기/단기) 추천 요소 생성

3.2 사업성 산출
├─ 3.2.1 `BuildRevenueModel`
│   ├─ 평형별 분양가/임대가 → 총수입 계산
│   ├─ 분양률/공실률 시나리오 3가지 (Base/Optimistic/Conservative)
├─ 3.2.2 `EstimateCost`
│   ├─ 설계 물량 추출 (Floorplan JSON → Quantity Take-off)
│   ├─ 자재·노무 단가 매핑 → 공종별 비용
│   └─ 금융비용, 부대비용 포함 Total Cost
└─ 3.2.3 `EvaluateFeasibility`
    ├─ NPV/IRR/Payback 계산
    ├─ 민감도 분석 (분양가 ±5%, 공사비 ±5%)
    └─ 리스크 요인 및 대응 전략 리포트화

### 🧠 4단계: 설계 생성 파이프라인 (Design Generator)
4.1 공간 프로그램 생성
├─ `LLMPlanner`
│   ├─ 입력: 요구사항, 건축사 스타일, 법규 제약
│   └─ 출력: 공간 리스트, 면적 배분, 우선순위 (JSON)

4.2 매스 & 배치 생성
├─ `MassingOptimizer`
│   ├─ 강화학습 + 제약조건 기반 볼륨 생성
│   └─ 일조/조망 시뮬레이션 → penalty 적용
└─ `CorePlacementSolver`
    ├─ 코어(계단/엘리베이터) 위치 최적화
    └─ 피난/소방 조건 만족 검증

4.3 평면/입면 생성
├─ `FloorplanGenerator`
│   ├─ Graph 기반 셀 분할 → SVG/IFC 변환
│   ├─ 동선 검증 (Shortest Path 분석)
├─ `FacadeComposer`
│   ├─ 스타일 템플릿 + 생성 모델 → 입면 패턴
│   └─ 에너지 기준/창 면적 비율 체크
└─ `ParkingLayoutGenerator`
    ├─ 요구 주차 대수 만족하는 레이아웃 생성
    └─ 차량 동선 시뮬레이션 (Agent 기반)

4.4 결과 패키징
├─ `GenerateDeliverables`
│   ├─ 도면: IFC, DXF, PDF 도면 세트
│   ├─ 3D: GLTF, Web Viewer Asset
│   └─ 요약 보고서: Markdown → PDF (WeasyPrint)
└─ `PublishArtifacts`
    ├─ S3에 저장 후 서명 URL 발행
    └─ 메타데이터 `deliverables` 테이블 업데이트

### 🔁 5단계: 피드백 학습 루프 (Learning Loop)
5.1 피드백 수집
├─ `CaptureFeedback`
│   ├─ UI/Slack/Email 링크로 수정 요청 접수
│   └─ 태그: 공간 구성, 마감, 동선, 비용, 기타
└─ `FeedbackNLP`
    ├─ 텍스트 임베딩 → 스타일 벡터 업데이트
    └─ 수정 이력 Diff 추출 → Feature Store 반영

5.2 지속 학습
├─ `DailyRetrainingPipeline`
│   ├─ 신선 데이터 검증 (Great Expectations)
│   ├─ Ray Tune로 하이퍼파라미터 탐색
│   └─ MLflow에 버전 등록
└─ `CanaryDeployment`
    ├─ Triton 모델 슬롯 10% 트래픽 배정
    └─ 성능 하락 시 즉시 롤백 (Argo Rollouts)

### 📦 6단계: 결과 전달 및 모니터링
6.1 알림 및 배포
├─ `NotifyClient`
│   ├─ Email + Slack + WebPush
│   └─ 파트너 제안 포함 (시공/금융)
└─ `UpdateDashboard`
    ├─ Next.js 대시보드 프로젝트 상태 업데이트
    └─ 주요 KPI 그래프 리프레시

6.2 관측성 & 로깅
├─ `EmitMetrics`
│   ├─ 워크플로우 실행 시간, 모델 추론 latency
│   └─ 비용 추정 오차, 사용자 피드백 점수
└─ `AuditTrail`
    ├─ 설계 생성 입력/출력 스냅샷 저장 (암호화)
    └─ 7년 보관 정책 + 삭제 요청 처리
